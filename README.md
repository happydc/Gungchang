# 궁창 제작도면 생성기

만든 사람: @용현정 이동철

각궁에 도지개를 채울 때 쓰는 **궁창**(궁틀, 활창애)의 제작도면을 만드는 웹 프로그램입니다.
치수를 입력하면 조립도, 부재도, 재단표를 그리고, 치수가 쓰기에 무리가 없는지 검사합니다.

## 바로 쓰기

https://happydc.github.io/Gungchang/ — 설치 없이 브라우저에서 실행합니다. 윈도우, 맥, 휴대폰 모두 됩니다.

- 도면 생성기: 위 주소
- 도지개 채우기 시뮬레이션: https://happydc.github.io/Gungchang/sim/

## 다루는 형식

| 형식 | 구성 |
|---|---|
| 전통 목재형 | 지지판 + 걸이대 2개 + 걸이봉 + 받침(이동식) |
| 개량 롤러형 | 목재 바닥틀 + 철판 본대 + 롤러 4개(반쪽) |

전통형에서 고를 수 있는 것

- 걸이대 결합: 지지판 옆면 턱끼움(기본) / 관통장부 + 쐐기 / 나사·목심 고정
- 걸이대 머리: 직각 / 모서리 굴림 / 반원
- 지지판 윤곽: 장방형 / 모서리 굴림 / 무릎 쪽 끝 둥글게
- 걸이봉: 둥근 봉 / 각재, 한쪽 손잡이 연장

## 도면 내보내기

도면마다 버튼이 있습니다.

- **SVG 저장**: 실제 크기(mm)로 저장합니다.
- **DXF 저장**: 1:1, CAD·레이저 커팅·CNC용. 한글 주석은 빠지고 치수 숫자만 들어갑니다.
- **1:1 인쇄**: 그 도면만 실제 크기로 인쇄합니다. 인쇄 설정에서 배율을 100%로 두세요. 종이보다 큰 부재(지지판 등)는 DXF나 SVG를 쓰세요.

## 기본 치수

| 항목 | 전통형 | 롤러형 |
|---|---|---|
| 지지판(바닥틀) | 900 × 250 × 40 | 500 × 250 × 40 |
| 걸이봉 아랫면 높이 | 205 | 205 (축 높이 230, 롤러 Ø50) |
| 받침 윗면 높이 | 188 | 195 (축 높이 170) |
| 걸이봉 ↔ 받침 | 받침을 80~300 사이로 옮겨 가며 사용 | 축간 40~145 (장공) |

단위는 mm입니다. 기본값은 시뮬레이션으로 정한 값이므로 제작 전에 실물과 대조해 확인하세요.

## 치수를 정한 근거

궁창은 지렛대입니다. 도지개의 줌통 쪽 끝을 활에 먼저 묶고, 그 끈을 걸이봉 밑에 건 다음, 도지개를 받침에 얹고 고자 쪽 활채를 눌러 도지개에 붙여 묶습니다. 아랫장을 먼저 채우고, 그 상태에서 윗장을 채웁니다.

시뮬레이션에서 확인한 것

- 받침 윗면이 걸이봉 아랫면보다 10~25 낮아야 도지개가 수평에 가깝게 놓입니다.
- 손을 넣어 끈을 묶으려면 도지개 밑 공간이 100 이상 필요합니다. 굴곡이 깊은 도지개(3형)까지 쓰려면 걸이봉 아랫면이 185 이상이어야 합니다.
- 묶는 위치(줌통 끝에서 띄우는 거리)는 궁창 치수에 거의 영향을 주지 않습니다.
- 받침을 걸이봉에 너무 붙이면(약 70 이내) 도지개 끝에 걸려 활이 곧추섭니다.

도지개 형상은 [각궁도지개 제작도면 생성기](https://github.com/happydc/dojigae-drawing)의 기본값(길이 360)을 썼습니다.

## 직접 빌드

```
bash build.sh        # _site 폴더에 index.html, sim/index.html 생성
```

빌드 도구나 외부 라이브러리는 필요 없습니다. `_site/index.html`을 브라우저로 열면 됩니다.

## 파일

- `src/gen/` — 도면 생성기
  - `draw.js` 도면 그리기 도구(SVG, DXF)
  - `trad.js` 전통 목재형, `roller.js` 개량 롤러형
  - `ui.js` 입력 화면, 저장·인쇄
- `src/sim/` — 도지개 채우기 시뮬레이션
- `build.sh` — 사이트 조립
- `.github/workflows/pages.yml` — main에 올리면 GitHub Pages에 배포
